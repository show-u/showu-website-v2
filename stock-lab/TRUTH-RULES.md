# StockLab 台股資料與預測不可違反規則

這份文件是 StockLab 的硬性規格。功能、UI、排名、速度與「一定要有答案」都不得凌駕於以下規則。

1. **合法來源優先**：任何會進入分數、價格模型、推薦或公開快取的資料，必須先有可重用的授權依據。網址可讀不等於可自動抓取或再散布。授權未確認時，一律視為不可用。
2. **未知永遠不是 0**：缺失、連線失敗、欄位改名、日期不符、資料過期、授權不明，一律保留為 `unavailable/null`；不得補 0、沿用舊值、猜欄位、拿同業值代替或用模型值冒充資料。
3. **觀測、推導、預測分開**：官方原始欄位是 `observed`；由官方欄位計算的是 `derived`；價格／分數是 `model_estimate`。三者在資料結構與 UI 上不得混稱。
4. **日期由來源證明**：不能因為 API 請求使用某日期，就替回傳資料補上該日期。每個 scored factor 必須有來源本身可驗證的交易日、公告日或報表期別。
5. **欄位只能精確解析**：會影響模型的官方結構化資料，只接受已登錄欄位名／schema；不得使用模糊字串搜尋來猜「哪個欄位大概是融資餘額」。
6. **歷史行情必須完整到足以支撐週期**：盤前/當日最少 60 根有效日 K；短線最少 80；中期最少 120；長期最少 220。最近行情過期或歷史有異常長中斷時，不產生價格預測。
7. **台股交易制度是硬限制**：價格必須符合 TWSE/TPEx 升降單位、開盤競價基準、漲跌幅、初上市例外、處置/分盤/停牌與信用交易限制；不是一般美股模型套台灣資料。
8. **公司行動先於技術模型**：除權息、減資、分割、合併、新上市等造成參考價不連續時，若沒有官方參考價調整，就停止以昨收為錨的盤前／技術價格預測。
9. **沒有合法即時源就不講即時**：未接入合法即時行情前，不顯示「現在價格、即時五檔、試撮成交價」等字樣。只能明示最新官方收盤／延遲資料日期。
10. **注意／處置必須是有效狀態**：歷史公告不能直接當成今天仍在處置。只有公告日期／起訖區間與目標交易日吻合才能標記；查不到時顯示「未驗證」，不能顯示「無旗標」。
11. **產業與會計格式不能猜**：產業未知時不做同業估值。一般業、金融業、保險業、證券期貨業、金控業、異業財報不得互套；未支援 schema 就不給該財務分。
12. **模型分數不是機率**：未經統計校準與樣本外驗證，不得稱「勝率、成功率、可信度 80%」。只能稱研究分數／模型估算。
13. **缺關鍵 Gate 就停止輸出**：必要資料不足時，結果應是「資料不足／未驗證／不產生價格」，不是為了版面完整而給一個數字。
14. **回測不能自我欺騙**：必須含台灣交易成本、稅、滑價、tick、成交條件；採時序 OOS；有效股票至少 120/160；每模式 OOS 至少 100 筆成交且至少 30 檔股票。看過 OOS 後再調參數，該 OOS 必須作廢並換新測試集。
15. **開放資料必須顯名**：使用政府資料開放授權條款資料時，網站與快取 metadata 必須標示提供機關、資料集及 OGDL v1 授權；未登錄授權的 raw dataset 不准公開鏡像。

## 現行保守決策

- TWSE T86 上市個股三大法人明細：在 StockLab 的授權 registry 尚無可確認的 OGDL/契約依據，因此停止自動抓取與計分；不得用空值補 0。
- TPEx 上櫃三大法人明細：政府資料開放平台資料集 11856，OGDL v1，可在符合顯名義務下使用。
- TWSE/TPEx 月營收、一般業季報、估值、行情等已登錄 OGDL 資料，仍須逐筆通過日期、schema、完整度檢查。
- 國際事件、VIX/SOX/NASDAQ、台指期：未完成對應個股的 OOS 校準前僅做觀察層，不直接改股票分數。

**總原則：寧可顯示「不知道」，也不顯示一個看起來完整但來源、日期或方法不成立的數字。**
