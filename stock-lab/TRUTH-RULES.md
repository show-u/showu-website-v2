# StockLab 台股資料與預測不可違反規則

這份文件是 StockLab 的硬性規格摘要；完整可執行規則以 `HARD_POLICY.md`、`verification-policy.json` 與對應 validation protocol 為準。功能、UI、排名、速度與「一定要有答案」都不得凌駕於以下規則。

1. **合法來源優先**：任何會進入模型、價格、排名、持股判斷或公開快取的資料，必須有明確可使用的授權依據。網址可讀、官方網站、公開 API 都不等於自動抓取、衍生使用或再散布授權。授權未確認時一律不可作模型事實。
2. **未知永遠不是 0**：缺失、連線失敗、schema 改變、日期不符、資料過期或授權不明，一律保留 `unavailable/null`；不得補 0、平均值、中位數、前一期、同業值、其他未驗證網站或 AI 推估。
3. **觀測、使用者輸入、推導、模型估計分離**：市場直接事實是 `observed`；持股成本／股數／買入日是 `user_observed`；確定性計算是 `derived`；預測與決策是 `model_estimate`。不得混稱。
4. **日期由來源證明**：每個市場事實必須有來源本身可驗證的交易日、公告日或報表期別；不能因請求參數用了某日期，就替資料補上該日期。
5. **欄位只能精確解析**：會影響模型的結構化資料只接受已登錄 schema／欄位名；不得用模糊搜尋猜欄位。
6. **歷史資料必須完整**：買入模型最少使用政策規定的有效歷史樣本；持股出場模型目前至少需要 120 根合法有效日線，且首次買入日必須存在於已驗證交易日序列。異常中斷、缺公司行動調整或來源不完整時停止模型輸出。
7. **台股交易制度是硬限制**：價格必須符合 TWSE／TPEx 升降單位、參考價、漲跌幅、集合競價、特殊無漲跌幅期間、注意／處置／分盤／停牌與商品種類規則。
8. **公司行動先於價格模型**：除權息、減資、分割、合併、新上市等造成價格基準不連續時，若沒有合法且已驗證的參考價／調整資料，就停止價格模型。
9. **沒有合法即時源就不講即時**：未接入合法即時／延遲行情前，不顯示「現在價格、即時五檔、試撮成交價」。盤中只能保留以最新完成交易日建立的原始計畫作參考，不得用昨日資料重算成「現在可執行價」。
10. **交易日由資料日期決定，不由時鐘猜**：13:30 收盤後，若今日官方收盤與所有必要輸入尚未驗證完成，就顯示「等待今日資料」，不得直接生成明日價格。只有資料日期真正前進且合法交易日曆確認下一交易日後，才能建立下一交易日模型。
11. **注意／處置必須是目標交易日有效狀態**：查不到就是未知，不能顯示「無旗標」。
12. **產業與會計格式不能猜**：一般業、金融、保險、證券期貨、金控與其他格式不得互套；未知分類不給產業基本面／估值分數。
13. **模型分數不是機率**：未經正式 untouched OOS 校準，不得稱勝率、成功率、可信度或信心百分比。
14. **缺關鍵 Gate 就停止輸出**：必要資料、合法性、日期、OOS、可執行性或信心校準任何一項失敗，結果就是「未取得／未通過驗證」，不是為版面完整而給數字。
15. **回測不能自我欺騙**：必須使用合法可重用的歷史資料、時序 OOS、台灣交易成本與實際成交限制；production formula 與 tested formula 必須一致。看過 untouched OOS 後修改公式，就必須升版並建立新的 untouched OOS。
16. **開放資料必須顯名與守授權**：政府開放資料保存資料集 ID、提供機關與 OGDL 證據；未確認 raw redistribution 權利的資料不得公開鏡像。

## StockLab 只有三種決策

### A. 不知道買什麼

使用與單股入場相同的完整模型做候選排名。最多顯示 10 檔；只有 3 檔通過就顯示 3 檔，0 檔就顯示 0 檔。**不得為了湊 TOP10 補入未通過 Gate 的股票。**

### B. 想買這檔

只使用一套統一入場模型回答「是否適合建立新部位」與「在所有執行 Gate 通過後，可參考的目標交易日進場區間」。

- **不再使用短／中／長選單產生不同買價。**
- 深層支撐只能作條件或等待區，不能包裝成現在可買價格。
- 公開進場區間必須在 OOS 中另外驗證觸價率、成交可達性與未成交率。
- 必須標示資料基準交易日與模型適用交易日。
- 盤中沒有合法即時行情時，不做同日重新報價。

### C. 已持有

持股是部位管理／出場問題，不是再找一組「短中長買價」。必要資料來自使用者：成本均價、目前股數、首次買入日；也可逐筆輸入仍持有部位的買入日、價格與股數，由系統加權。

- 實際持有時間以買入日至最新完成交易日的**真實交易日數**計算。
- 模型可以使用買入日前的歷史行情建立結構，但不能把那些日期算進持有天數。
- 股數只用於市值與金額損益；沒有總資產／風險預算時，不因股數改變技術出場訊號。
- 出場採「條件優先、價格次之」：續抱、獲利保護、減碼、停利或出場都必須由當時可取得且已驗證的資料決定。
- 收盤形成的出場訊號，最早只能對下一合法可交易時段提出執行條件；不得使用事後高低點製造漂亮成交。
- 正式 OOS、出場可執行性與信心校準未全部 PASS 前，不顯示可執行賣價。

## 現行保守決策

- TWSE T86 上市個股三大法人明細：授權 registry 目前未確認可供 StockLab 自動處理／再利用的明確依據，因此維持 blocked，不得用空值補 0。
- 政府資料開放平台已確認 OGDL 的資料集，仍必須逐筆通過 schema、日期、完整性、商品分類與用途 Gate。
- 國際市場、台指期與國際事件只有在來源、授權、日期與模型契約全部成立時才能成為正式模型輸入；「沒有事件資料」不等於「沒有事件」。
- 正式 licensed historical bundle 尚未啟用前，入場／出場模型維持 fail-closed；不以網站抓取補洞。

**總原則：寧可顯示「不知道」，也不顯示一個看起來完整但來源、日期、交易制度或方法不成立的數字。**
